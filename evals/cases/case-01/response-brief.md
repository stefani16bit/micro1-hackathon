# Response brief — case-01

> **STATUS: to be produced from the pilot run. Not frozen.**

## Why this file is empty

An earlier draft of this file organised the candidate's facts *as answers to questions written in
advance*. That was wrong, for a reason worth recording: the interview's questions are generated by
the model from the slot plan and the job description. Only the opening is fixed. A brief that
anticipates the questions pushes the respondent to fit their answer to prepared material, which is
the opposite of what it exists to do — and it required the assistant to invent specifics the CV
does not state.

So the order is inverted. **The brief is an output of the pilot run, not an input to it.**

## How it gets made

1. Run the pilot. The opening answer is typed live; every other question is whatever the model
   generates.

   ```
   .venv\Scripts\python.exe -m solution.adapters.cli --iteration 0 --pilot
   ```

2. The candidate answers honestly from memory and from the CV. No preparation, no script.

3. The transcript is transcribed into this file as **facts organised by competency** — not as
   question-and-answer pairs. Everything in it is then something the candidate actually said,
   which means it contains no invented specifics at all.

4. The opening answer the candidate typed is frozen verbatim into `opening-answer.md`.

5. From that point the brief serves its real purpose: holding the *content* constant across the
   eleven measured runs, so the interviewer's questions are the only moving variable.

## Rules for the respondent, once this is frozen

1. **Answer from this brief.** If a question reaches something genuinely not here, answer honestly,
   then add the fact afterwards and note it in `CHANGELOG.md`. The brief grows; it is not quietly
   rewritten.
2. **Do not improve your answers between runs.** A sharper way of telling the same story is a
   change to the experiment. It goes into the brief before the *next* run and it gets recorded —
   otherwise later iterations look better for a reason unrelated to the system.
3. **Answer naturally.** Do not pad to fill the 120 seconds, and do not compress to look efficient.
