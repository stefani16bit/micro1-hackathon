Job Title: Full Stack Developer
Job Type: Contractor
Location: Remote
Openings: 50

## About the role

micro1 is selecting skilled Full Stack Developers to support a customer's innovative
project. In this role, you'll apply your end-to-end development expertise to help train
next-generation AI systems. Your work will shape how models learn, reason, and perform
through high-quality, real-world input. No prior experience in AI is required - your
development skills are what matter.

As an expert, you will be creating Reinforcement Learning Environments which test an AI
model's ability to solve full-stack software problems, spanning frontend, backend, and the
connection between them. You will be tasked with creating a reproducible environment and a
golden reference solution for the problem.

## Scope of Work

- Contribute clear code samples, debugging approaches, and development insights across
  frontend and backend, using languages like JavaScript/TypeScript, Python3, Java, or Go.
- Identify, troubleshoot, and resolve bugs that span both the UI and the underlying API or
  database layer.
- Build small to medium features end-to-end, from the interface through to the data layer,
  following good coding practices.
- Improve existing frontend and backend code to make it cleaner, more consistent, and
  easier to maintain.
- Document your reasoning, approach, and code decisions to support AI training data
  quality.
- Review peer-contributed code and technical submissions for correctness and clarity.

## Preferred Qualifications

- 1+ years of hands-on experience building both frontend and backend applications.
- Comfortable with at least one frontend framework (React, Vue, or Angular) and one backend
  stack (Node/Express, Python/Django/Flask, Java/Spring, or similar).
- Solid understanding of how frontend and backend systems connect through APIs.
- Ability to debug issues that cross the frontend/backend boundary.
- Good documentation and communication skills to explain your technical decisions clearly.
- Interest in or curiosity about AI and its technical challenges (previous AI experience
  not required).
